# Portafolio Web

## Descripción

Portafolio personal de Carlos A. Vazquez Tohorton, desarrollado como proyecto del Sprint 4.

El sitio presenta información sobre el perfil profesional, habilidades y herramientas, proyectos destacados y datos de contacto.

El proyecto está diseñado para ser responsivo y adaptarse a diferentes tamaños de pantalla, incluyendo dispositivos móviles, tabletas y computadoras de escritorio.

## Tecnologías y técnicas utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Diseño web responsivo
- Media queries
- Git
- GitHub
- Figma
- Fuentes personalizadas mediante `@font-face`
- Imágenes SVG y PNG
- `aspect-ratio` para imágenes responsivas
- `object-fit` para mantener las proporciones de las imágenes
- `linear-gradient` y `radial-gradient` para efectos visuales
- Pseudoelementos CSS (`::after`)
- Efectos `:hover`
- Enlaces externos y enlaces `mailto:`
- HTML semántico
